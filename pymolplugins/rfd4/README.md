# RFD4 · Proteina

打开 **Plugin → PymolPlugins: RFD4 · Proteina**。面板嵌入 PyMOL 主窗口，按“输入 → 编辑 → 生成 → 结果”组织操作。它随 PymolPlugins 安装和更新，不需要独立插件或启动命令。

## 连接与迁移

客户端需要 PyMOL 自带的 Qt、Python 3.9+ 标准库。模型、AtomWorks 和 GPU 留在服务端。连接设置接受启用 PyMOL protocol 1 API 的 Studio 根地址，不带 `/design/`：HTTPS 可直接连接，SSH 转发使用 `http://127.0.0.1:本地端口`。服务必须提供 candidate、轨迹和条件评估接口；旧 Web 服务需先升级。

填写访问令牌并勾选“记住登录”后，打开面板自动连接，计算后端按服务保存。Windows 使用当前用户 DPAPI 加密，Linux 使用权限 0600 的用户文件；QSettings 不含令牌。取消记住登录会删除该地址的凭据。连接失败时可在设置中重试，不自动重提生成任务。

从独立 RFD4-PyMOL 0.2.1 迁移时，地址、默认后端、任务 ID 和凭据位置保持不变。请在 Plugin Manager 中禁用旧 `rfd4_pymol` 并完全重启，再使用 PymolPlugins 菜单。保留原 `Molaison/RFD4Studio` 设置及 `~/.pymol/rfd4_credentials`。安装包不含账号凭据、模型或科学样例输出。

## 工作流

- **输入**：导入注释 CIF、服务端示例，或已有 PyMOL 对象。导入选项集中在折叠区。普通 PyMOL 对象需重新指定设计条件。
- **编辑**：选择原子或残基，按类别设置条件。结构操作只展示当前表单，修改在服务端保存修订与撤销历史。
- **生成**：选择后端、Thinking 和数量；seed、partial diffusion 等放在高级采样。需要轨迹时勾选“保存轨迹”；后端必须支持全原子 x1 保存。
- **结果**：选中 candidate，点击“下一轮”创建独立输入，保留完整注释、父任务和轮次。可修改条件后继续生成，原结果保留。partial diffusion 需明确开启。

“查看工具”直接复用同一 PymolPlugins 中的配色、Contacts 和按序列选择，并提供服务端相互作用分析。“更多”集中提供叠合比较、CIF 和批次 ZIP 导出；PyMOL 普通 save/PSE 不代替完整注释 CIF。

## 预览已应用的条件

打开输入后点 **预览条件**。预览区显示输入修订、已应用条件和当前生成参数，应用编辑或撤销后随输入刷新。概览突出片段和热点，大片坐标分组作为背景。选中一项可单独高亮对应原子，双击把实际原子载入 PyMOL 选择。点击“返回概览”恢复简洁显示。未展开的可变片段显示长度范围和示意点，颜色随已应用的二级结构条件。服务端仅提供数量的条件会显示为无定位信息。

PyMOL 的 3D Viewer 和对象栏可在预览时继续使用。关闭预览会清除临时副本和标记。预览只读取已经载入的修订和当前面板参数。

## 轨迹与条件

选中 candidate 后打开“轨迹”，拖动滑块或播放。轨迹 x1 是生成步骤对干净结构的预测，不是分子动力学；序列和原子数可随帧变化。没有可靠 step/time 时横轴称“保存帧”，最终 candidate 单独显示。没有轨迹的任务仍可检查最终结构，不补造中间帧。自动适配视野只调整相机，不改原始坐标。

可检查当前帧或整条轨迹。表格显示“满足 / 原始目标数”，保留无法判断和不支持数量；点击条件行定位目标和配对距离。氢键默认仅检查链间，观察链内氢键需在检测设置取消这一限制。判据检测供体/受体角色是否存在合适配对，不要求保留输入中的同一个配对原子。

可评估氢键、疏水、π 堆积、π 阳离子、盐桥和金属配位。其他条件仍可编辑和传给模型，但评估标为不支持。缺原子或身份对应不可靠时标为无法判断；unindexed 目标没有原生逐帧插入对应关系时标为不支持，均不从原始分母删除。这是局部几何与化学证据，不是结合能或模型条件损失。

网络中断后，在底部“任务”中用原任务 ID 查询。任务查询受服务保存期限和进程重启限制；不要因断线重复提交。取消等待会丢弃结果，已经开始的模型计算仍会安全退出。

## 来源

客户端来自 `239_rfd4_proteina_web_interface` 的 RFD4-PyMOL 0.2.1，集成时保留其科学交互和凭据合同。上游验收包括 beta PyMOL 3.1.8 上两轮真实 f102 推理、从 candidate 继续、变拓扑轨迹和氢键评估；本次合并以统一安装包与实际 PyMOL 菜单验收为准。科学生成和轨迹分析实现属于服务端，不随客户端打包。
